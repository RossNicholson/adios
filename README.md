# Adios

**A free, open-source ad and tracker blocker for Safari on Mac.** Install the app, enable the extension, and browse with fewer ads and trackers — with per-site controls when you need them.

* **Blocking** — Fewer third-party ads, trackers, and noisy requests in Safari.
* **Toolbar** — Open the Adios button to turn blocking on or off, see stats, and tweak the current site (including “allow ads on this site”).
* **Privacy** — No sign-up, no account, and no data sent to us; everything runs on your Mac.

---

## Install

```bash
brew tap rossnicholson/tap
brew install --cask adios
```

Or download the latest **`.dmg`** from [Releases](https://github.com/RossNicholson/Adios/releases) and drag **Adios** into Applications.

**Requirements:** macOS 15 or later · Safari

After installing, **open Adios once**, then in Safari go to **Safari → Settings → Extensions**, enable **Adios**, and enable **Adios Content Blocker** if it appears separately. When Safari asks for access to websites, choose **Always Allow** where you want blocking. If anything looks odd after an update, **quit Safari completely** (⌘Q) and reopen it.
