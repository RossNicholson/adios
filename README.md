# Adios

**A free, open-source ad and tracker blocker for Safari on Mac.** Install the app, enable the extension, and browse with fewer ads and trackers — with per-site controls when you need them.

[![Latest release](https://img.shields.io/github/v/release/RossNicholson/adios)](https://github.com/RossNicholson/adios/releases/latest) [![License](https://img.shields.io/github/license/RossNicholson/adios)](LICENSE) ![macOS](https://img.shields.io/badge/macOS-15%2B-blue) ![Safari](https://img.shields.io/badge/Safari-extension-orange)

---

- **Blocking** — Fewer third-party ads, trackers, and noisy requests in Safari.
- **Toolbar** — Turn blocking on or off, see stats, and tweak per site — including "allow ads on this site".
- **Privacy** — No sign-up, no account, no data sent anywhere. Everything runs on your Mac.

---

## Install

```bash
brew tap RossNicholson/tap
brew install --cask adios
```

Or download the latest `.dmg` from [Releases](https://github.com/RossNicholson/adios/releases) and drag Adios into Applications.

**Requirements:** macOS 15+ · Safari

After installing, open Adios once, then go to **Safari → Settings → Extensions**, enable **Adios** and **Adios Content Blocker**. When Safari asks for website access, choose **Always Allow**. If anything looks odd after an update, quit Safari (⌘Q) and reopen it.
