Adios is a simple, efficient, and privacy-focused ad blocker for Safari on iOS and macOS. It helps you browse the web faster and safer by blocking ads, trackers, and other unwanted content.

## Features

- 🚫 Blocks ads and trackers across websites
- 📊 Shows real-time blocking statistics
- 🔒 Protects your privacy
- ⚡️ Improves page load times
- 📱 Works on both iOS and macOS
- 🎯 Site-specific controls
- 💾 Tracks data savings
- 🛡️ No data collection or tracking

## Installation

### iOS
1. Download Adios from the App Store
2. Open iPhone Settings
3. Scroll down and tap Safari
4. Tap Extensions
5. Find Adios and turn it ON

### macOS
1. Download Adios from the App Store
2. Open Safari
3. Click Safari in the menu bar
4. Click Settings...
5. Click Extensions
6. Find Adios and check the box to enable it

## Privacy

Adios needs permission to read webpage content to identify and block ads effectively. While this means Adios can see the content of web pages, we:
- Never collect personal information
- Never store your browsing data
- Never transmit any data
- Never track your activity

## Features in Detail

### Ad Blocking
- Blocks common ad networks
- Removes ad elements from pages
- Prevents tracking scripts
- Blocks unwanted pop-ups

### Statistics
- Number of ads blocked
- Data saved from blocked content
- Site-specific blocking stats
- Real-time monitoring

### Site Controls
- Allow ads on specific sites
- Custom rules per domain
- Easy toggle for trusted sites
- Exception management
